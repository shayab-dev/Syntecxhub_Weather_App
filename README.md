# 🌦️ Syntecxhub_Weather_App

This repository contains my **Internship Project 1**, developed during my internship as a **Frontend Web Developer at Syntecxhub**.

The project is a responsive weather application developed using **HTML, CSS, and JavaScript**. It allows users to search for a location and view relevant weather information through a simple and user-friendly interface.

The **Syntecxhub Weather App** is a frontend-based weather application created to practice and demonstrate practical web development skills.

## ⚙️ How It Works

The application follows a simple workflow:

1. User enters a city or location in the search field.
2. JavaScript captures the user's input.
3. The application sends a request to the weather API.
4. The API returns the relevant weather information.
5. JavaScript processes the response.
6. The weather information is dynamically displayed on the webpage.
7. Appropriate error handling is provided when the location cannot be found.
